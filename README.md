# Sync Store — Landing

Marketing site built with Next.js (App Router) and Tailwind CSS.

## Prerequisites

- Node.js 22 LTS (minimum 20.9)

## Install and run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run start      # serve the production build
npm run lint
```

## Environment

No environment variables are needed yet. `.env.example` is a placeholder. Browser-visible variables must be prefixed with `NEXT_PUBLIC_`.
